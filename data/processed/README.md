# Processed data

These files are generated by `src/prepare_analysis.py` and are the inputs to the Tableau workbook.

- `dashboard_kpis.csv`: headline full-population results plus the sampled surface-model result, with scope recorded for each metric.
- `clue_difficulty_summary.csv`: exact distribution statistics by clue count.
- `difficulty_heatmap.csv`: exact counts for each clue-count and rating combination.
- `tier_summary.csv`: provisional catalogue tiers and population shares.
- `structural_sample.csv`: deterministic random sample with engineered surface features.
- `feature_correlations.csv`: sample correlations with difficulty.
- `model_comparison.csv`: out-of-sample baseline and surface-feature model performance.
- `anomaly_examples.csv`: representative puzzles that contradict the fewer-clues-equals-harder assumption.
- `validation_summary.csv`: source-quality checks and their scope.
