# Tableau deliverable

Open `Sudoku Difficulty Audit.twb` in Tableau Desktop. Keep the adjacent `Data/` directory with the workbook because the `.twb` uses that relative local source.

The charts use clue counts 21–28 (99.98% of the catalogue) to prevent 518 sparse-tail records from distorting the visual comparison. Dashboard KPIs and the documented hypothesis tests use all 3,000,000 records.
