# Tableau deliverable

Open `Sudoku Difficulty Audit.twb` in Tableau Desktop. Keep the adjacent `Data/` directory with the workbook because the `.twb` uses that relative local source.

The charts use clue counts 21–28 (99.98% of the catalogue) to prevent 518 sparse-tail records from distorting the visual comparison. Dashboard KPIs, correlations and grouped summaries use all 3,000,000 records; the surface-feature model uses the documented 100,000-row sample.
